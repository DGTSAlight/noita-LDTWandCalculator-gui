# ✦ NOITA 跃迁计算器 GUI ✦

**Noita LongDistanceTravel Calculator GUI** —— 两个单文件 HTML 工具，无需任何环境，双击即可运行，支持离线使用。

| 工具 | 解决的问题 |
|---|---|
| **跃迁法术收集计算器**（v0.1.0） | 我想飞这么远，**还差哪些法术** |
| **速度跃迁计算器**（v0.7） | 我有这些修正，**能飞多远** |

> 🌐 **Language / 切换语言**：[English](README.en.md) · 中文（当前）

## 一、跃迁法术收集计算器（v0.1.0）

勾选你已有的法术与数量，工具反推所有可行的跃迁配置，按**收集难度**排序，并高亮还缺什么。

### 功能特性

#### 🌿 速度触手跃迁页

- 🔍 **搜索上/下飞个数** —— 默认上限 100，以 α 池为主轴反解指数。
- 🧩 **α 池** —— 10 种速度修正（总数 ≤5）× 法杖 3 档 × 粘液弹 1.1 档。
- 🛠️ **校准器、刷新环、回绕** —— 均可开关；回绕只允许一次。

#### 🌌 黑洞闪电弹跃迁页

- 💫 **双载体闭式距离** —— 黑洞 + 闪电弹的距离之和逼近目标。
- 🪄 **法杖倍率可选** —— 不限 1.0（26 格）/ 迅捷之杖 1.25（19 格）/ 多重之杖 1.5（26 格）/ 两者都搜。
- 📐 **误差区间** —— 额外显示黑洞 ±7f 造成的距离偏差上下界。

#### 🌀 相位跃迁页

- 🎯 **三种载体** —— 定时能量球 100f；失效触发黑洞 + 混沌拉帕 300f / 复制轨迹 200f。
- ⏱️ **跳跃次数** —— 失效帧与跳跃帧重叠时吞一跳；定时载体不吞跳。
- 🔢 **相位个数上限 1600** —— 超过 90 份时标红提示「必须配加速」。

#### 通用

- 🧾 **三块分组** —— 复制链 + 回绕 / 额外速度乘数 / 必须组件、可选组件。
- 🟥 **缺口高亮** —— 缺失法术标红，文案「缺 1（有 0 / 需 1）」。
- 📊 **收集难度** —— 单次概率取倒数后按 3-范数聚合，数值越小越容易凑齐。
- 🛡️ **内置自检** —— 按当前页运行对应检查，切换页签自动清空。

### 使用方法

1. 双击 `跃迁法术收集计算器GUI_v0.1.0.html`。
2. 左侧勾选已拥有的法术；数量留空按 1 计。
3. 设置目标距离、误差容限、同种法术上限等参数。
4. 点「开始计算」，结果按收集难度从小到大排列。

### 文件说明

- `跃迁法术收集计算器GUI_v0.1.0.html` —— 单文件，约 150 KB。

## 二、速度跃迁计算器（v0.7）


### 项目简介

**NOITA 速度跃迁计算器 GUI** 是一个单文件 HTML/CSS/JavaScript 应用，内置两个跃迁计算器：

- **速度触手跃迁** —— 解决《Noita》游戏中 α_other 分解问题的经典计算器。
- **黑闪跃迁（黑洞 + 闪电弹双载体）** —— 计算施加给黑洞和闪电弹的存在时间修正与速度修正的合理组合。

无需安装任何环境，双击即可运行，可完全离线使用。

### 功能特性

#### 🌿 触手跃迁页

- 🎯 **预设距离** —— `NG+0`（35,840 像素 / 1 世界）与 `NG+1`（32,768 像素），或自定义任意距离。
- ⚡ **指数级乘数** —— 可配置上/下飞数量，并支持任意“底数/指数”附加条目（例如 1.3²）。
- 🧩 **α_other 分解** —— 组合 9 种普通速度修正法术及可选的“起始 20 倍”：
  | 数值 | 修正          |
  | ---- | ------------- |
  | 0.33 | 相位          |
  | 0.32 | 逐渐加速      |
  | 0.3  | 沉重一击      |
  | 0.75 | 易爆          |
  | 1.2  | 闪灭          |
  | 1.68 | 逐渐减速      |
  | 7.5  | 轻盈一击      |
  | 2.5  | 加速          |
  | 2    | 蛇形/混沌轨迹 |
- 🪄 **法杖与粘液弹** —— 法杖自带倍率可固定 `×1.0`，或在 `1 / 1.25 / 1.5` 中自动选择；粘液弹 `×1.1` 是 α_other 中 1.1 倍乘数的唯一来源，且不计入修正个数上限。
- 📐 **误差与排序** —— 支持相对百分比 / 绝对像素两种误差模式，按“误差优先”或“因子最少优先”排序，每页显示 10/20/30 条方案；普通修正个数上限可调（默认 5，最大 12）。
- 🔁 **复制普通因子（v0.6）** —— 每个普通因子可使用 1 次或复制 `1..N` 次（N ≤ 800，默认 100）。搜索受每步钳制 ≤ 20、饱和剪枝（如 `7.5²` 已被钳制到 20）以及节点/时间上限（800 万节点 / 8 秒）保护；当深度搜索可能较久时会出现提示徽标。

#### 🌌 黑闪跃迁页（v0.7）

- 💫 **双载体计算** —— 黑洞（v₀ = 2/3 px/s，阻力 ξ = −0.2，基础存在 120f ± 7f，速度上限 1000/60 px/f）与闪电弹（v₀ = 90 px/s，ξ = 0.55，存在 1f，上限 1024 px/f）。距离之和为总距离；与目标距离比对时黑洞取**中间值**，同时呈现 ±7f 的最大/最小距离。
- ⏱️ **存在时间修正** —— 蓝表 +75f · 无害化（黑洞/普通投射物 +280f，闪电弹 +281f）· 红表 −42f。存在时长必须为正。
- 🧮 **速度修正** —— 黑闪页仅适用 5 种速度因子（加速 ×2.5、逐渐加速 ×0.32、沉重一击 ×0.3、易爆 ×0.75、轻盈一击 ×7.5）；每个逐渐加速自第 2 帧起使阻力 ξ −3（多个叠加）。
- 🪄 **法杖与粘液弹** —— 法杖乘数仅影响黑洞（不限制模式或固定 1.25/1.5）；粘液弹 `×1.1` 不计入修正个数。
- 🔁 **复制修正** —— 可选（默认关闭），仅允许复制 `2 / 3 / 4 / 6 / 8 / 10` 次；一次复制可包含多个速度因子，最多允许两种不同的复制次数；复制时修正个数上限取 `min{5, 用户设定上限}`。
- 🔍 **子集搜索模式** —— 可选（默认关闭）：黑洞与闪电弹受到的修正必须满足一方的修正是另一方的子集。
- 📐 **误差距离范围展示** —— 计算结果以误差距离范围呈现，如 `[-100.0 ~ +100.0]`（实测黑洞 ±7f 贡献为 `[-6.9 ~ +7.1]`）。
- 🛡️ **内置回归自检** —— 黑闪页共 8 项（T1–T8）：xls 社区方案回归、闭式公式 vs 逐帧（480 用例，最大相对误差 7.52e-15）、±7f 范围、存在时长为正、端到端复现、复制约束、子集搜索，以及无害化分类（闪电弹 +281f）/ 禁用因子（相位、蛇形/混沌轨迹已剔除）。

#### 通用

- 🖼️ **完全自包含** —— 全部法术图标以 base64 内嵌，无外部资源、无需联网，离线可用。双击文件即运行。
- 🎨 **双页面 SPA** —— 通过顶部标签在触手/黑闪两个计算器间淡入切换；背景装饰定时触发黑洞、闪电弹、蓝表与鹿。

### 使用方法

1. 下载（或克隆）`速度跃迁计算器GUI_v0.7.html`。或者[在线体验]( https://dgtsalight.github.io/noita-calcu/)本项目。
2. 双击该 HTML 文件，即可在现代浏览器（Chrome / Edge / Firefox）中直接打开。
3. 通过顶部标签 **「✦ 触手跃迁 / ✦ 黑闪跃迁」** 切换页面。
4. 选择距离预设（或输入自定义距离），配置搜索参数，点击 **「✦ 开始计算 ✦」**。
5. 每个页面底部均有可折叠的 **自检** 面板（触手页 T1–T12、黑闪页 T1–T8），一键运行全部回归测试。

### 文件说明

- `速度跃迁计算器GUI_v0.7.html` —— 整个应用仅此一个文件（约 150 KB）。

## 三、源码分析

### 3.1 单文件结构

| 段 | 内容 |
|---|---|
| `<style>` | 主题变量、布局、装饰层 |
| `window.SPELL_DATA` | 58 个法术的权重数据（JSON 内嵌） |
| `window.ICON_DATA` | 58 个图标 base64 |
| `window.LDT` | 算法引擎（UMD，可单独提取） |
| 末尾 IIFE | 界面逻辑（面板、参数、渲染、自检） |

### 3.2 引擎模块

| 模块 | 职责 |
|---|---|
| `CFG` | 全部常量：世界宽度、相位节奏、法杖容量、载荷预设、可选组件 |
| `DN` | 一分为多链枚举（位置约束 = 迭代极限）、可达份数集合 |
| `Weights` | 百分比 → 单次概率 q（按等级频率归一） |
| `Phase` | 跳跃次数与距离 |
| `Tentacle` | α 池构建 + 反解 n |
| `BlackFlash` | 闭式距离 + 双载体二分配对 |
| `Score` | 收集难度（3-范数）与排序 |
| `Format` | 三块分组与缺口文案 |

### 3.3 关键算法

1. **相位距离** —— `d = 28 × P × J`。定时载体 `J = floor((T−1)/12)`；限制类 `J = floor(L/12)`，`L % 12 == 0` 时再 −1。
2. **触手距离** —— `d = 7.92 × 1.2^n × α`。对每个 α 反解 `n = log(D / (7.92α)) / log 1.2`，取上下取整。
3. **黑闪距离** —— 沿用 v0.7 闭式公式，两载体距离求和后与目标比对。
4. **收集难度** —— `q(s) = Σ f(t)·pct/100 ÷ Σ f(t)`，`c(s) = 1/q(s)`，`S = (Σ(缺口 × c)^3)^(1/3)`。
5. **DN 可达份数** —— 116 条合法链、37 种乘积；≤1600 有 46.2% 的整数可达。

### 3.4 二次开发

- 引擎不依赖 DOM。把 `window.LDT` 抽出来即可用于 CLI 或 Node 脚本。
- 构建：`python scripts/impl/build.py` 把 `src/` 下的模板、样式、引擎、图标组装成单文件。
