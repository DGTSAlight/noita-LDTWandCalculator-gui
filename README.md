### Overview

**Noita LongDistanceTravel Calculator GUI** is a single-file HTML/CSS/JavaScript application that solves the long-distance-travel (LDT) problems in the game *Noita*. It bundles two calculators in one file:

- **Tentacle Warp** — the classic α_other(the accurate speed multiplier you need to compete LDT) decomposition search for speed-tentacle warps.
- **Black-Hole + Lightning Bolt Warp** (black-flash warp) — searches valid combinations of lifetime modifiers and speed modifiers applied to both a **Black Hole** and a **Lightning Bolt**.

### Features

#### 🌿 Tentacle Warp page

- 🎯 **Distance presets** — `NG+0` (35,840 px / 1 world) and `NG+1` (32,768 px), or a fully custom distance.
- ⚡ **Exponential multipliers** — configurable up/down-flight count and arbitrary extra exponential chips (e.g. 1.3²).
- 🧩 **α_other decomposition** — combines 9 normal speed modifiers plus the optional "start ×20" step:
  | Value | Modifier                                  |
  | ----- | ----------------------------------------- |
  | 0.33  | Phasing Arc (相位)                        |
  | 0.32  | Accelerating Shot (逐渐加速)              |
  | 0.3   | Heavy Shot (沉重一击)                     |
  | 0.75  | Explosive (易爆)                          |
  | 1.2   | Fizzle (闪灭)                             |
  | 1.68  | Decelerating Shot (逐渐减速)              |
  | 7.5   | Light Shot (轻盈一击)                     |
  | 2.5   | Speed Up (加速)                           |
  | 2     | Slithering / Chaotic Path (蛇形/混沌轨迹) |
- 🪄 **Staff & slime** — staff speed bonus fixed `×1.0` or auto-choose among `1 / 1.25 / 1.5`; slime pellet `×1.1` is the only source of a 1.1 multiplier inside α_other and does not count toward the modifier count limit.
- 📐 **Tolerance & sorting** — relative percentage or absolute-pixel error mode, sort by error or by fewest modifiers, page size 10/20/30, up to 12 modifiers with a configurable cap (default 5).
- 🔁 **Copy ordinary factors (v0.6)** — each normal factor may be used once or copied `1..N` times (N ≤ 800, default 100). The search is protected by per-step clamping at `20`, saturation pruning (e.g. `7.5²` already clamps to 20), plus node/time limits (8M nodes / 8 s); a warning badge appears when deep searching may take a while.

#### 🌌 Black-flash Warp page (v0.7)

- 💫 **Dual carrier** — Black Hole (v₀ = 2/3 px/s, drag ξ = −0.2, base lifetime 120f ± 7f, speed cap 1000/60 px/f) and Luminous Drill (v₀ = 90 px/s, ξ = 0.55, lifetime 1f, cap 1024 px/f). Flight distances are summed, and the error against the target distance uses the Black Hole's **mid lifetime value** while min/max distances are shown as well.
- ⏱️ **Lifetime modifiers** — Blue Table +75f · Harmless (Black Hole / normal projectiles +280f, Luminous Drill +281f) · Red Table −42f. Effective lifetime must stay positive.
- 🧮 **Speed modifiers** — the black-flash page only uses 5 factors (Accelerating Shot ×2.5, Gradual Acceleration ×0.32, Heavy Shot ×0.3, Explosive ×0.75, Light Shot ×7.5); each Gradual Acceleration additionally lowers ξ by 3 starting from frame 2.
- 🪄 **Staff & slime** — staff multiplier affects only the Black Hole (unrestricted mode or fixed 1.25/1.5); slime `×1.1` does not consume a modifier slot.
- 🔁 **Copy modifiers** — optional, fixed to `2 / 3 / 4 / 6 / 8 / 10` copies, one group may contain several speed factors, at most two distinct copy counts; the modifier cap is `min{5, user cap}` while copying.
- 🔍 **Subset search mode** — optional (off by default): the modifiers of one carrier must be a subset of the other carrier's.
- 📐 **Error-distance range display** — results are shown as an error range like `[-100.0 ~ +100.0]` (e.g. `[-6.9 ~ +7.1]` for the Black Hole ±7f contribution).
- 🛡️ **Built-in regression self-test** — the black-flash page runs 8 checks (T1–T8): xls community-plan regression, closed-form vs per-frame (480 cases, max rel. error 7.52e-15), ±7f range, positive-lifetime enforcement, end-to-end reproduction, copy constraints, subset search, and the harmlessness classification (drill +281f) / banned factors (Phasing Body & Chaotic Path are excluded).

#### Shared

- 🖼️ **Fully self-contained** — all spell icons are embedded as base64 data URIs; no external resources, no network access, works offline. Double-click the file and it runs.
- 🎨 **Two-page SPA** — switch between the two calculators with a fade animation; the background decoration animates Black Holes, Luminous Drills, a Blue Table and a Deer.

### Usage

1. Download (or clone) `速度跃迁计算器GUI_v0.7.html`. Or experience it [online](https://dgtsalight.github.io/noita-calcu/).
2. Double-click the HTML file — it opens directly in any modern browser (Chrome / Edge / Firefox).
3. Switch page with the top tabs: **“✦ 触手跃迁 / ✦ 黑闪跃迁”**.
4. Pick a distance preset (or enter a custom one), configure the search parameters, then click **“✦ 开始计算 ✦”**.
5. Each page has a collapsible **self-test** panel (tentacle: T1–T12; black-flash: T1–T8) that runs all regression checks with one click.

### 项目简介

**NOITA 速度跃迁计算器 GUI** 是一个单文件 HTML/CSS/JavaScript 应用，内置两个跃迁计算器：

- **速度触手跃迁** —— 解决《Noita》游戏中 α_other 分解问题的经典计算器。
- **黑闪跃迁（黑洞 + 闪电弹双载体）** —— 计算施加给黑洞和闪电弹的存在时间修正与速度修正的合理组合。

无需安装任何环境，双击即可运行，可完全离线使用。

### 功能特性

#### 🌿 触手跃迁页

- 🎯 **预设距离** —— `NG+0`（35,840 像素 / 1 世界）与 `NG+1`（32,768 像素），或自定义任意距离。
- ⚡ **指数级乘数** —— 可配置上/下飞数量，并支持任意“底数/指数”附加条目（例如 1.3²）。
- 🧩 **α_other 分解** —— 组合 9 种普通速度修正法术及可选的“起始 20 倍”：
  | 数值 | 修正          |
  | ---- | ------------- |
  | 0.33 | 相位          |
  | 0.32 | 逐渐加速      |
  | 0.3  | 沉重一击      |
  | 0.75 | 易爆          |
  | 1.2  | 闪灭          |
  | 1.68 | 逐渐减速      |
  | 7.5  | 轻盈一击      |
  | 2.5  | 加速          |
  | 2    | 蛇形/混沌轨迹 |
- 🪄 **法杖与粘液弹** —— 法杖自带倍率可固定 `×1.0`，或在 `1 / 1.25 / 1.5` 中自动选择；粘液弹 `×1.1` 是 α_other 中 1.1 倍乘数的唯一来源，且不计入修正个数上限。
- 📐 **误差与排序** —— 支持相对百分比 / 绝对像素两种误差模式，按“误差优先”或“因子最少优先”排序，每页显示 10/20/30 条方案；普通修正个数上限可调（默认 5，最大 12）。
- 🔁 **复制普通因子（v0.6）** —— 每个普通因子可使用 1 次或复制 `1..N` 次（N ≤ 800，默认 100）。搜索受每步钳制 ≤ 20、饱和剪枝（如 `7.5²` 已被钳制到 20）以及节点/时间上限（800 万节点 / 8 秒）保护；当深度搜索可能较久时会出现提示徽标。

#### 🌌 黑闪跃迁页（v0.7）

- 💫 **双载体计算** —— 黑洞（v₀ = 2/3 px/s，阻力 ξ = −0.2，基础存在 120f ± 7f，速度上限 1000/60 px/f）与闪电弹（v₀ = 90 px/s，ξ = 0.55，存在 1f，上限 1024 px/f）。距离之和为总距离；与目标距离比对时黑洞取**中间值**，同时呈现 ±7f 的最大/最小距离。
- ⏱️ **存在时间修正** —— 蓝表 +75f · 无害化（黑洞/普通投射物 +280f，闪电弹 +281f）· 红表 −42f。存在时长必须为正。
- 🧮 **速度修正** —— 黑闪页仅适用 5 种速度因子（加速 ×2.5、逐渐加速 ×0.32、沉重一击 ×0.3、易爆 ×0.75、轻盈一击 ×7.5）；每个逐渐加速自第 2 帧起使阻力 ξ −3（多个叠加）。
- 🪄 **法杖与粘液弹** —— 法杖乘数仅影响黑洞（不限制模式或固定 1.25/1.5）；粘液弹 `×1.1` 不计入修正个数。
- 🔁 **复制修正** —— 可选（默认关闭），仅允许复制 `2 / 3 / 4 / 6 / 8 / 10` 次；一次复制可包含多个速度因子，最多允许两种不同的复制次数；复制时修正个数上限取 `min{5, 用户设定上限}`。
- 🔍 **子集搜索模式** —— 可选（默认关闭）：黑洞与闪电弹受到的修正必须满足一方的修正是另一方的子集。
- 📐 **误差距离范围展示** —— 计算结果以误差距离范围呈现，如 `[-100.0 ~ +100.0]`（实测黑洞 ±7f 贡献为 `[-6.9 ~ +7.1]`）。
- 🛡️ **内置回归自检** —— 黑闪页共 8 项（T1–T8）：xls 社区方案回归、闭式公式 vs 逐帧（480 用例，最大相对误差 7.52e-15）、±7f 范围、存在时长为正、端到端复现、复制约束、子集搜索，以及无害化分类（闪电弹 +281f）/ 禁用因子（相位、蛇形/混沌轨迹已剔除）。

#### 通用

- 🖼️ **完全自包含** —— 全部法术图标以 base64 内嵌，无外部资源、无需联网，离线可用。双击文件即运行。
- 🎨 **双页面 SPA** —— 通过顶部标签在触手/黑闪两个计算器间淡入切换；背景装饰定时触发黑洞、闪电弹、蓝表与鹿。

### 使用方法

1. 下载（或克隆）`速度跃迁计算器GUI_v0.7.html`。或者[在线体验]( https://dgtsalight.github.io/noita-calcu/)本项目。
