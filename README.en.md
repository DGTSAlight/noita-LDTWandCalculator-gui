## 1. Spell Collection Calculator (v0.1.1)

Tick the spells you already own. The tool searches every viable warp build, ranks them by **collection difficulty**, and highlights what is still missing.

### Features

#### 🌿 Tentacle warp page

- 🔍 **Searches the up/down-flight count** — cap 100 by default; the exponent is solved from an α pool.
- 🧩 **α pool** — 10 speed modifiers (total count ≤ 5) × 3 staff tiers × slime pellet.
- 🛠️ **Calibrator and staff multiplier are mutually exclusive** — a calibrator bypasses the wand's hidden speed multiplier, so at most one of the two is used. The calibrator itself is optional (you can aim by hand); with it on, the staff dropdown stays clickable and is merely labelled "bypassed".
- ↕️ **Up-flight and down-flight are interchangeable** — the tentacle ignores direction and turns the speed entirely into launch-direction velocity, so the tool picks whichever you own or can get more easily.

#### 🌌 Black-hole + lightning bolt page

- 💫 **Dual carrier, closed-form distance** — the sum of both carrier distances approaches the target.
- 🪄 **Staff multiplier** — none 1.0 (26 slots) / Swift Wand 1.25 (19 slots) / Multishot Wand 1.5 (26 slots) / search all three; the card shows the matching staff icon.
- 🚀 **Black hole must leave the loaded area** — it has to travel ≥ 2048 px or the lightning bolt hits a wall. Toggleable, on by default.
- 📐 **Error range** — also shows the distance band caused by the black hole's ±7f lifetime.
- 🗂️ **Required components split in two rows** — which modifiers go on the black hole, which on the lightning bolt.

#### 🌀 Phase warp page

- 🎯 **Carriers** — Timed Energy Orb 100f; Death-trigger Black Hole / Intense Concentrated Light + Chaotic Larpa 300f or Copy Trail 200f.
- ⏱️ **Jump count** — a jump that lands on the expiry frame is swallowed; timed carriers never swallow.
- 🔢 **Phase cap 1600** — above 90 phases the card flags "speed modifier required".
- 🦌 **Swapper restriction** — only builds whose payload rides on "Add Death Trigger" can use the swapper deer; picking it automatically rules out the timed energy orb.

#### Shared

- 🧾 **Zones** — copy chain / extra speed multipliers / required components / payload / optional components. Wrap-around gets its own badge so nobody assumes every build needs it.
- 📖 **Official Chinese names** — spells are labelled with the official wiki names, and the spell panel shows the speed multiplier (×7.5) or lifetime change (+75f) inline.
- 🔗 **Copy-chain helpers added automatically** — two chains get 2 "Add \*Trigger" spells plus the refresh ring; one chain copying several spells gets 1; one chain copying a single spell gets none.
- 🏷️ **Multi-role spells** — Light Shot counts as both a speed and a damage modifier, Linear Arc / Horizontal Path as both calibrator and damage; ticking one ticks them all.
- 🟥 **Gap highlight** — missing spells are red, labelled "missing 1 (have 0 / need 1)"; the long form appears once per card.
- 📊 **Collection difficulty** — reciprocal of the per-roll probability, aggregated with a 3-norm; lower is easier.
- 📱 **Collapsible spell panel** — collapse with ☰ on desktop; on narrow screens it becomes a drawer so it no longer covers the calculator.
- 🛡️ **Built-in self-test** — runs the checks of the current page; switching tabs clears it.

### Usage

1. Double-click `跃迁法术收集计算器GUI_v0.1.1.html`.
2. Tick the spells you own on the left; an empty count means 1 (tap ☰ on narrow screens).
3. Set the target distance, tolerance and per-spell cap.
4. Click "开始计算". Results are sorted from easiest to hardest.

### File

- `跃迁法术收集计算器GUI_v0.1.1.html` — the whole tool in one file (~183 KB), works offline.

## 2. Speed Warp Calculator (v0.7)


### Warning：
The English content on this page is largely generated by AI translation, and some technical terms may differ from those used in the English-speaking community. To avoid misunderstandings, readers are advised to refer to the Chinese version of Noita Wiki when reading this page.
[Chinese Wiki](https://noita.wiki.gg/zh/wiki/Noita_Wiki)

### Overview

**Noita LongDistanceTravel Calculator GUI** is a single-file HTML/CSS/JavaScript application that solves the long-distance-travel (LDT) problems in the game *Noita*. It bundles two calculators in one file:

- **Tentacle Warp** — the classic α_other(the accurate speed multiplier you need to compete LDT) decomposition search for speed-tentacle warps.
- **Black-Hole + Lightning Bolt Warp** (black-flash warp) — searches valid combinations of lifetime modifiers and speed modifiers applied to both a **Black Hole** and a **Lightning Bolt**.

### Features

#### 🌿 Tentacle Warp page

- 🎯 **Distance presets** — `NG+0` (35,840 px / 1 world) and `NG+1` (32,768 px), or a fully custom distance.
- ⚡ **Exponential multipliers** — configurable up/down-flight count and arbitrary extra exponential chips (e.g. 1.3²).
- 🧩 **α_other decomposition** — combines 9 normal speed modifiers plus the optional "start ×20" step:
  | Value | Modifier                                  |
  | ----- | ----------------------------------------- |
  | 0.33  | Phasing Arc (相位)                        |
  | 0.32  | Accelerating Shot (逐渐加速)              |
  | 0.3   | Heavy Shot (沉重一击)                     |
  | 0.75  | Explosive (易爆)                          |
  | 1.2   | Fizzle (闪灭)                             |
  | 1.68  | Decelerating Shot (逐渐减速)              |
  | 7.5   | Light Shot (轻盈一击)                     |
  | 2.5   | Speed Up (加速)                           |
  | 2     | Slithering / Chaotic Path (蛇形/混沌轨迹) |
- 🪄 **Staff & slime** — staff speed bonus fixed `×1.0` or auto-choose among `1 / 1.25 / 1.5`; slime pellet `×1.1` is the only source of a 1.1 multiplier inside α_other and does not count toward the modifier count limit.
- 📐 **Tolerance & sorting** — relative percentage or absolute-pixel error mode, sort by error or by fewest modifiers, page size 10/20/30, up to 12 modifiers with a configurable cap (default 5).
- 🔁 **Copy ordinary factors (v0.6)** — each normal factor may be used once or copied `1..N` times (N ≤ 800, default 100). The search is protected by per-step clamping at `20`, saturation pruning (e.g. `7.5²` already clamps to 20), plus node/time limits (8M nodes / 8 s); a warning badge appears when deep searching may take a while.

#### 🌌 Black-flash Warp page (v0.7)

- 💫 **Dual carrier** — Black Hole (v₀ = 2/3 px/s, drag ξ = −0.2, base lifetime 120f ± 7f, speed cap 1000/60 px/f) and Luminous Drill (v₀ = 90 px/s, ξ = 0.55, lifetime 1f, cap 1024 px/f). Flight distances are summed, and the error against the target distance uses the Black Hole's **mid lifetime value** while min/max distances are shown as well.
- ⏱️ **Lifetime modifiers** — Blue Table +75f · Harmless (Black Hole / normal projectiles +280f, Luminous Drill +281f) · Red Table −42f. Effective lifetime must stay positive.
- 🧮 **Speed modifiers** — the black-flash page only uses 5 factors (Accelerating Shot ×2.5, Gradual Acceleration ×0.32, Heavy Shot ×0.3, Explosive ×0.75, Light Shot ×7.5); each Gradual Acceleration additionally lowers ξ by 3 starting from frame 2.
- 🪄 **Staff & slime** — staff multiplier affects only the Black Hole (unrestricted mode or fixed 1.25/1.5); slime `×1.1` does not consume a modifier slot.
- 🔁 **Copy modifiers** — optional, fixed to `2 / 3 / 4 / 6 / 8 / 10` copies, one group may contain several speed factors, at most two distinct copy counts; the modifier cap is `min{5, user cap}` while copying.
- 🔍 **Subset search mode** — optional (off by default): the modifiers of one carrier must be a subset of the other carrier's.
- 📐 **Error-distance range display** — results are shown as an error range like `[-100.0 ~ +100.0]` (e.g. `[-6.9 ~ +7.1]` for the Black Hole ±7f contribution).
- 🛡️ **Built-in regression self-test** — the black-flash page runs 8 checks (T1–T8): xls community-plan regression, closed-form vs per-frame (480 cases, max rel. error 7.52e-15), ±7f range, positive-lifetime enforcement, end-to-end reproduction, copy constraints, subset search, and the harmlessness classification (drill +281f) / banned factors (Phasing Body & Chaotic Path are excluded).

#### Shared

- 🖼️ **Fully self-contained** — all spell icons are embedded as base64 data URIs; no external resources, no network access, works offline. Double-click the file and it runs.
- 🎨 **Two-page SPA** — switch between the two calculators with a fade animation; the background decoration animates Black Holes, Luminous Drills, a Blue Table and a Deer.

### Usage

1. Download (or clone) `速度跃迁计算器GUI_v0.7.html`. Or experience it [online](https://dgtsalight.github.io/noita-calcu/).
2. Double-click the HTML file — it opens directly in any modern browser (Chrome / Edge / Firefox).
3. Switch page with the top tabs: **“✦ 触手跃迁 / ✦ 黑闪跃迁”**.
4. Pick a distance preset (or enter a custom one), configure the search parameters, then click **“✦ 开始计算 ✦”**.
5. Each page has a collapsible **self-test** panel (tentacle: T1–T12; black-flash: T1–T8) that runs all regression checks with one click.

## 3. Source Code Overview

### 3.1 Single-file layout

| Section | Content |
|---|---|
| `<style>` | Theme variables, layout, decoration layer |
| `window.SPELL_DATA` | Weights and multi-role data of 51 spells (inlined JSON) |
| `window.ICON_DATA` | 51 spell icons + 2 staff icons as base64 |
| `window.LDT` | Algorithm engine (UMD, extractable) |
| Trailing IIFE | UI logic (panel, parameters, rendering, self-test) |

### 3.2 Engine modules

| Module | Responsibility |
|---|---|
| `CFG` | All constants: world width, phase cadence, staff tiers and capacities, payload presets, optional components, role zones |
| `DN` | Divide-N chain enumeration (position rule = iteration limit), reachable copy counts |
| `Weights` | Percentage → per-roll probability q (normalised by tier frequency) |
| `Phase` | Jump count and distance |
| `Tentacle` | α pool construction and exponent solving |
| `BlackFlash` | Closed-form distance and two-carrier pairing |
| `Score` | Collection difficulty (3-norm) and ordering |
| `Zone` | Zone construction, merging, equivalence picking (up/down flight, Linear Arc / Horizontal Path, …) |
| `Chain` | Copy-chain helper rules (how many Add \*Trigger spells, when the refresh ring is mandatory) |
| `Format` | Zones → display items + gap labels |

### 3.3 Core algorithms

1. **Phase distance** — `d = 28 × P × J`. Timed carriers: `J = floor((T−1)/12)`. Lifetime-limited carriers: `J = floor(L/12)`, minus 1 when `L % 12 == 0`.
2. **Tentacle distance** — `d = 7.92 × 1.2^n × α`. For each α solve `n = log(D / (7.92α)) / log 1.2`, then try the floor and the ceiling.
3. **Black-flash distance** — the v0.7 closed-form formula; both carrier distances are summed and compared with the target.
4. **Collection difficulty** — `q(s) = Σ f(t)·pct/100 ÷ Σ f(t)`, `c(s) = 1/q(s)`, `S = (Σ(gap × c)^3)^(1/3)`.
5. **Reachable DN counts** — 116 legal chains, 37 distinct products; 46.2% of integers up to 1600 are reachable.
6. **Copy-chain helpers** — `chains ≥ 2 → 2 Add \*Trigger spells + refresh ring`; `one chain, several spells → 1`; `one chain, one spell → 0`; `wrap-around → refresh ring mandatory`.
7. **Equivalence classes** — up/down flight, Linear Arc / Horizontal Path, death-trigger black hole / Delayed Spell, and the three Add \*Trigger spells are interchangeable; the tool picks one by "already owned → easier to obtain" so it never counts a substitute twice.

### 3.4 Reuse

- The engine has no DOM dependency. Extract `window.LDT` to build a CLI or a Node script.
- Build: `python scripts/impl/build.py` assembles the template, styles, engine and icons from `src/` into one file.
