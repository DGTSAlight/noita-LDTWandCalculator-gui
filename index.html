✦ NOITA 黑闪跃迁计算器 ✦

载体：黑洞（v₀ = 2/3 px/f · ξ = −0.2 · 存在 120f ± 7f · vmax = 1000/60）  +  闪电弹（v₀ = 90 px/f · ξ = 0.55 · 存在 1f · vmax = 1024）

速度递推：vn+1 = min(vn · (1 − ξ/60), vmax)；每个「逐渐加速」自第 2 帧起 ξ 额外 −3；法杖速度乘数只作用于黑洞初速

⚠ 黑洞闪电弹配置具有大量弊端，请谨慎使用。新手玩家即使运用该配置，也请尽快换成触手或相位跃迁配置。

① 目标跃迁距离

NG + 0（35,840 像素 / 1 世界） NG + 1（32,768 像素） 自定义

② 搜索参数（修正数量 = 时间 + 速度修正种类总和，每载体上限 8）

启用（不计入修正数量；两载体共享）
⚠ 开启后计算时间可能较久
复制次数只允许 2 / 3 / 4 / 6 / 8 / 10；最多两种不同复制次数；一次复制可复制多个速度因子（「逐渐加速」对 ξ 的影响叠加）；启用复制时修正上限取 min{5, 用户上限}。
